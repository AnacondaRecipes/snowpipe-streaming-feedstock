Installing snowpipe-streaming
==================

Installing `snowpipe-streaming` from the main channel can be achieved by:

```
conda install snowpipe-streaming
```

It is possible to list all of the versions of `snowpipe-streaming` available on your platform with `conda`:

```
conda search snowpipe-streaming
```
